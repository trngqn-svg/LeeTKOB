# What the assistant may do

Enforced for Claude Code by [`.claude/settings.json`](../.claude/settings.json). The same
three tiers apply to any other tool the team uses.

| Tier          | Actions                                                                                                                                                                                                                                                                             | Why                                                                                                                                                                                  |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Allowed**   | Read the code. Edit `src/` and docs other than the contract. Run the four checks (`lint`, `format`, `format:check`, `typecheck`, `test`). `git status / diff / log / switch / add`.                                                                                                 | Reversible and local.                                                                                                                                                                |
| **Ask first** | Install or remove a package. `git commit / push / tag / merge / rebase`. Edit `tests/`, `docs/contract/` or `.github/workflows/`. Any network call (`curl`). Any `docker` command, for example to build the sandbox or checker image or to run an attack submission.                | A test, the contract or CI can be changed to make a check pass. Pushing and tagging are visible to others. A new package is new code we trust. Docker on a machine is close to root. |
| **Never**     | Read `.env` or any real secret. Push to `main`, force-push, `reset --hard`, rewrite history. `rm -rf`. Give a container `--privileged`, the Docker socket, a host mount, `--env-file` or a secret in `-e`. That covers the judging sandbox above all. Call a real model from tests. | Leaks a secret or destroys work that cannot be recovered. A sandbox with any of these loses the minimums of the brief (section 5).                                                   |

These tiers are for the coding assistant. Team members and CI use Docker as their tasks need: the sandbox tests run in CI, and the deployment runs on the VM (`docs/DEPLOYMENT.md`).
