# Modular Exponentiation

Given $q$ queries, each with three integers $a$, $b$, $m$ ($0 \le a, b \le 10^9$, $1 \le m \le 10^9$), print $a^b \bmod m$ on its own line.

Assume $0^0 = 1$.

## Input

The first line contains $q$. Each of the next $q$ lines contains $a$, $b$, $m$.

## Output

Print $q$ lines, each containing $(a^b) \bmod m$.
